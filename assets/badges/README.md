# Original club identity marks

ClubBadge paints resolution-independent, original geometric badges. The curated
catalog in `lib/data/club_visual_identity.dart` maps 79 verified V4 club IDs to
recognizable kit colors and short labels. Three shared app silhouettes (shield,
round, pennant) and the same asymmetric bands distinguish these from official
crests. No official club logo, crown, mascot, crest tracing or logo URL is used.

Unknown clubs use their supplied color or a neutral teal palette and initials.
They never inherit another club's identity via partial name matching. Real club
names remain visible beside marks. `badgeKey` remains supported for separately
supplied, appropriately licensed local WebP assets; this change adds none.

Colors and names help recognition but this is not a guarantee of trademark
clearance. League graphics are outside this change's scope.
